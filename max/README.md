# Карта камер для MAX

URL: https://playtoball.github.io/crascameras/max/
Бот: https://max.ru/se14692451_1_bot
В кабинете «MAX для бизнеса» выбрать этого бота → Настройки → URL мини-приложения.
Кнопка запуска: «Открыть».

Использует MAX Bridge: BackButton, HapticFeedback, openMaxLink, shareMaxContent.
Поддерживает прямые ссылки ?startapp=cam_N. Внешний сайт оператора открывается
через openLink. Камеры показываются внутри встроенного видеоплеера iframe.

Данные пользователя и токен бота не отправляются на сайт и не сохраняются.
Избранное и видеостена хранятся локально на устройстве. Авторизация для
просмотра публичных камер не требуется.

Корневая Telegram-версия сайта сохранена без изменений.
